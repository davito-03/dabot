Términos de uso

Al invitar Dabot o usar dabot.davito.es aceptas estos términos.

  1. Dabot se ofrece «tal cual». Davito puede cambiar módulos, pausar el servicio o expulsar el bot de un servidor que abuse de él (raid, spam, malware).
  2. Tú eres responsable de los permisos que otorgas al bot y de cumplir las condiciones de Discord. condiciones de Discord.
  3. Funciones Premium (copias de seguridad de estructura, IA extendida) pueden requerir suscripción. No hay reembolsos automáticos salvo lo que exija la ley.
  4. No uses Dabot para acoso, contenido ilegal o evadir las reglas de Discord. El operador puede borrar datos o denegar el servicio.
  5. El panel web es solo para quien tenga permiso de gestionar el servidor o un rol de staff asignado.
  6. El proceso de verificación web incorpora validaciones técnicas de seguridad orientadas a la prevención de abusos, intrusiones automatizadas y protección de la comunidad conforme a las políticas vigentes.
  7. Estos términos se interpretan junto a la política de privacidad. política de privacidad.
