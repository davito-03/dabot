Antes de verificar: desactiva VPN, proxies o redes intermediarias

Para garantizar la integridad y autenticidad del acceso, el proceso requiere una conexión directa sin redes VPN ni túneles de anonimización. Si utilizas alguno, desactívalo un momento, recarga e inténtalo de nuevo.

iPhone / iPad

  1. Private Relay: Ajustes → tu nombre → iCloud → Relé privado (Private Relay) → desactivar.
  2. Safari: Ajustes → Safari (o Ajustes → Apps → Safari) → Ocultar dirección IP → Desactivar. Si no aparece, con apagar Private Relay basta.
  3. VPN: Ajustes → General → VPN y gestión de dispositivos (o VPN) → desconecta cualquier perfil. En iOS 18: Ajustes → VPN y gestión de dispositivos.
  4. Apps: cierra Nord, Express, Surfshark, Proton, 1.1.1.1 / WARP, AdGuard VPN, etc. (el icono de VPN en la barra de estado tiene que desaparecer).
  5. Cierra Safari del todo (App Selector → desliza hacia arriba) y abre de nuevo este enlace. Wi‑Fi o datos móviles da igual; lo que no vale es el túnel.

Android

  1. Ajustes → Red e Internet → VPN → desconecta la sesión activa.
  2. En esa misma pantalla, desactiva VPN siempre activa / Always-on VPN (si está en on, se vuelve a conectar sola).
  3. Abre Nord / Express / Surfshark / Proton / 1.1.1.1 WARP / Opera y pulsa desconectar. Quita la llave o el escudo de la barra de notificaciones.
  4. No uses el VPN integrado de Opera ni extensiones tipo Hola / Urban VPN en Chrome.
  5. Cierra el navegador por completo y vuelve a abrir dabot.davito.es/verify.

Navegador (PC)

  1. Chrome / Edge: chrome://extensions o edge://extensions — desactiva Urban VPN, Proton, Hotspot Shield, Hola, SetupVPN, Touch VPN, etc.
  2. Firefox: about:addons → extensiones → desactiva cualquier VPN/proxy.
  3. Opera / Opera GX: Ajustes → Funciones avanzadas / Bloqueador → VPN → Off. El VPN naranja de Opera también cuenta.
  4. Cierra Tor Browser. Desconecta WARP / 1.1.1.1, Tailscale exit nodes, ZeroTier, WireGuard o OpenVPN del sistema (bandeja de Windows / icono de macOS).
  5. Recarga esta página (o pulsa Recomprobar red). No hace falta cambiar de Wi‑Fi si el túnel ya está apagado.
